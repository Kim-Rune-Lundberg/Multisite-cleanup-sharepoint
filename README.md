# Multisite-cleanup-sharepoint
Script to remove and delete historic versions of files located in the document library on sharepoint sites.

### Script description
Script is designed to check each site for the file extensions in the script. 
The script called "Multi-site-cleanup sharepoint.ps1" is designed to remove files related to AutoCAD and its file-extensions.
The script called "Versioning cleanup office revised" is designed to remove files related to Microsoft Office products. 
Scripts can be adjusted to your specific needs. 
I recommend downloading the scripts and modifying them to your needs. As the scripts are designed to be as generic as possible. 

NB!NB!NB! 
Be aware that with the persistent login on the scripts. This requires you to monitor the running of the script in case something goes wrong.
The persistent authentication on the sites will follow token time to live so be aware of that!
